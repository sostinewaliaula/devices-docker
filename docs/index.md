## Tech Stack

- **Frontend**: React + TypeScript + Vite
- **Backend**: Node.js + Express
- **Database**: MySQL / MariaDB / PostgreSQL (configurable)
- **Auth**: JWT + Google OAuth
- **AI**: Pluggable providers (OpenAI, Anthropic, Gemini, etc.)
